# 书籍网页阅读纠错覆盖层

`text-corrections.json` 只修复网页文字提取的高置信损伤，不改动原 PDF、原书网页文本 JSON 或原子知识单元。它不是重蒸馏，也不生成新的理论、案例、数字或交易规则。

## 适用范围与来源绑定

- 扩展书架共 2 本、61 页已完成字符及排版扫描：《自然法则》36 页，《缠中说禅》25 页。
- 本覆盖层只列真正发生纠错的 49 页：自然法则 27 页、缠论 22 页；其余 12 页继续使用原始文本。
- `source_pdf_sha256` 必须等于 `knowledge/source/library.json` 的登记值，并核对实际本地 PDF 文件。两本 PDF 的实际 SHA-256 已验证一致。
- 每个 `original_text_sha256` 是该书原始 `pages[].text` UTF-8 字节的 SHA-256，不是 JSON 文件字节或压缩空白后的值。原始文本改变时，纠错不能静默继续套用，应报明确错误并重新人工对照。
- 页码是蒸馏 PDF 页码，不是原著页码。正文中已有的原著 PDF/书页引文保持原样。

## 审查与变更原则

1. 检查了两个网页文字 JSON、117 个原子单元，以及全部 161 个公开知识页面。现有真源未检出替换乱码、私用区、零宽/方向控制、非换行控制字符、软连字符、HTML 实体残留或纯符号垃圾行。因此没有采用字符黑名单删减。
2. 每个覆盖页均完整对照该页原始 `text` 与本地蒸馏 PDF 提取内容；涉及统计表和示意链另用渲染图确认列含义及连接次序。
3. 只按已确认的具体标题、图题、课程组标题或段落首句作显式拆分，不使用泛化的 `第N章`/数字过滤来猜段落。
4. `##`/`###` 只标记 PDF 中已有的独立标题。管道表格按原表头、行、列恢复；所有表格都有标准 `---` 分隔行。
5. 保留浪级、斐波比例、百分比、数学符号、MACD、课程日期、历史措辞、争议观点，以及各条证据/医疗/原图边界。图注不能被当作垃圾删除。
6. 原 PDF 与 `knowledge/source/book-text/*.json` 全部保留原样，便于差异复核、回溯和撤销。删除本覆盖层条目即可恢复该页原始阅读文本，不需要重写原文。

## 明确保留的限制

- 《缠中说禅》仍是蒸馏文献，不是站内可逐篇读取的 1,135 篇 CHM 原文；本次没有恢复或伪造 CHM 缺失图片。
- 原 PDF 中的统计由本覆盖层忠实恢复到网页；这不代表本次重新验证了全部原博客统计或历史观点的事实真实性。
- 第10版核心知识此次只进行真源字段/公开页面检查；本覆盖层不修改它的 117 Units，也不声称重新视觉核验了原著 280 页。
- 内部知识 ID 应由阅读器显示为可点击的中文标题，不应因看似“乱符号”而从真源移除。指向隐藏候选案例的链接应过滤，不应重新公开案例。

## 复核要求

- 在应用覆盖层前检验书 ID、PDF SHA-256、原页文本 SHA-256、页号唯一性和完整文本。
- 使用只允许已支持块的安全渲染器显示标题、段落、列表和表格；不要把正文送入 `replace(/\s+/g, " ")`，不要执行 HTML。
- 搜索索引可折叠空白，但应使用同一已验证的纠错内容，避免搜索结果与阅读页数字不一致。
- 对缠论第 1、3、4、5、7、16、22、23 页及自然法则第 19 页进行桌面和窄屏展示抽查；验证比例、统计数、课名、图注与原 PDF 一致。

## 发布与回退边界

- 原始 PDF、原始网页提取 JSON、117 Units、146 个核心公开页面的内容字段保持不变；15 个候选页面恢复为其 Markdown 真源生成，6 条指向隐藏案例的关联不再输出到公开目录。
- 网页阅读数据和 AI 检索 artifact 由同一次构建更新。发布时需按现有流程同步 Gateway 与 Next，不应只换前端而把检索内容留在旧版。
- Gateway 仍严格固定知识版本；旧版已排队 AI 任务不会被静默改绑为新版，本次没有放宽版本校验或改通知/任务队列。
- 回退使用上一个完整发布版本；仅撤销某页纠错也可删除对应覆盖层条目后重新构建。不要改原始 PDF 或提取 JSON 来达到回退目的。
- 本轮没有涉及 Hermes 交易、订单、持仓、授权、风控或凭据。
