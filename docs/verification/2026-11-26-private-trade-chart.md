本轮还缺真实 iOS Safari/PWA、实际账号附件上传、五个提供方的独立环境复验和 API p95。当前仓库发布流程只有本机/CI 候选版和生产入口，未获得独立测试环境或指定交易账号。本地浏览器结果仅覆盖合成场景。生产尚未应用迁移。

网关通过 `TRADING_FILL_CHART_ENABLED` 控制图表访问，默认关闭。Web 从网关健康响应读取开关，Web 运行时也可独立设置 `TRADING_FILL_CHART_ENABLED=false` 隐藏图表。退回文字复盘时先关闭开关并重载对应服务，保留已保存备注、图表和追加迁移。验证时确认文字复盘仍可打开，图表 API 不返回数据。

内测时先在网关环境设置非空 `TRADING_FILL_CHART_PILOT_UIDS`，填写逗号分隔的已激活 WaveKB UID，再打开主开关。是否参与内测由网关根据已登录账号的资料判定，健康响应只公开开关状态。正式开放前，应分别用名单内、名单外与匿名账号检查图表权限，并在一次新同步结束后抽查早于迁移的交易，确认同步已生成逐笔成交分配。
