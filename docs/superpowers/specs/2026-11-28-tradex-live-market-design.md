# WaveKB 实时行情与逐笔复盘（TradeX）

用户已确认：用 `saifullahshafin/open-source-tradingview` 做实时行情底座，复用 WaveKB 的逐笔标记、备注和公开分享逻辑。先用币安 U 本位验收，验收通过前不全站开放。此设计补充 [原逐笔复盘规范](2026-11-26-interactive-trade-chart-sharing-design.md)，不改变原复盘的权限、附件、评论和既有快照。

## 用户看到的功能

- 交易工作台内增加「实时行情」，已登录的验收会员可使用；保留原逐笔复盘作为独立入口。没绑定交易账户也能看已授权公开的行情。
- 首版使用 Binance USDⓈ-M 的成交价 K 线。历史加载后展示真实推送的形成中 K 线，换周期正确切换订阅，断线显示状态，补齐缺口后恢复。交易所或行情不可用时明确说明，不拿现货、其他交易所或模拟数据冒充。
- 从已同步交易进入行情图时，自动选中相同市场和合约。所选交易里每个开仓、加仓、减仓、平仓或反手成交按实际时间和价格标记；重合点可展开，关闭标记不影响实时行情。点击后在 WaveKB 内读写该笔私有备注。
- 「分享复盘」沿用 WaveKB 公共策略的服务端预览和发布。明确列出分享范围，不把整段实时行情或后续成交变成公开流；盈亏金额、仓位数量、私有备注默认不公开。仅允许用户勾选可稳定重现的复盘画线、指标与备注；不兼容画线、指标明确告知，不静默发布另一份内容。

## 方案与边界

- 已选 TradeX 衍生版本：单独构建、部署和署名，使用专用来源域名；WaveKB 用受限 iframe 嵌入。采用 TradeX 的 Vela 主图、实时行情模块和自带画线/指标，不引入 MT5、订单路由或账户同步。先不开站内用户任意脚本。保留独立部署单元不代表自动满足许可证，发布前复核实际代码边界和对应源码。
- 对比直接合并进 WaveKB：调用更直接，但会将主站业务、构建和发版与第三方项目耦合，许可证及用户数据边界更难审核；不选。
- 对比只参考交互并继续用 OpenAlgo：可继续保持原有依赖，但不能复用 TradeX 已有的实时行情图表工具；用户已选择复用 TradeX。
- 只允许固定 HTTPS 模块来源；WaveKB 与它只交换经校验的市场定位、最小化标记（临时 ID、成交时间、价格、动作）和选中事件。WaveKB 独自持有会话、原始记录、账户凭据、备注正文和分享流程；不使用 URL 传递私有数据。
- 模块按 [AGPL 第 13 条](https://github.com/saifullahshafin/open-source-tradingview/blob/main/LICENSE#L551) 向联网用户提供对应源码并按 [NOTICE](https://github.com/saifullahshafin/open-source-tradingview/blob/main/NOTICE) 署名；WaveKB 使用自己的名字和标识。上线另核对行情显示权限、合适的上游连通性和流量限制。
- 仅在 WaveKB 的隔离测试环境、专用验收账户内验证；灰度和全站使用分离的开关。无私人交易 API 密钥的公开行情验证独立于成交同步验证。
