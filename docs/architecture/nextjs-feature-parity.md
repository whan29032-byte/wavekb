# WaveKB 旧站 → Next.js 功能对照

本清单是生产切流的验收门槛，不以“页面能打开”代替功能完成。状态分为：

- **已迁移**：Next.js 中已有等价的数据读写、权限与失败处理。
- **自动验证**：已有单元、构建、匿名 Playwright 或专用账号真实写入测试。
- **上线验收**：必须在 UCloud 预览或正式域名上使用真实后端完成。

## 切流前硬门槛

1. `pnpm typecheck`、`pnpm lint`、`pnpm test`、生产构建和 Storybook 构建全部通过。
2. Playwright 桌面与移动匿名路径全部通过。
3. 专用账号在 UCloud Next 预览完成：登录 → 简易发帖 → 图片/外链 → 评论 → 专业编辑/TradingView → 删除 → 退出；测试内容和文件被清理。
4. Nginx 配置先备份并通过 `nginx -t`，切换后验证首页、知识、五板块、登录、健康检查和真实发帖。
5. 保留旧静态目录、上一版 Next release 和一条命令回滚；任何健康检查失败立即恢复。
