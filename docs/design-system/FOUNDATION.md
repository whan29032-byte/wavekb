# WaveKB 设计基础

> 执行规范来自仓库内 `design-system-kit/`。本文件记录 WaveKB 的项目决策，不把工具包模板当成品牌本身。

## 视觉主张

**冷静的研究工作台：低彩度中性底、单一冷蓝主操作色、精确的数字字距、克制的边框与阴影，阅读优先。**

可检验特征：

1. 页面背景使用冷灰中性色，面板比页面亮一级；不靠发光或玻璃拟态制造层级。
2. 全站只保留一个主操作色；成功、警告、危险、信息各自使用独立语义色，不把所有文字染成蓝色。
3. 正文优先：知识阅读保持 60–72ch 行宽、1.7–1.86 行高；金额、统计、时间使用 tabular numerals。
4. 控件半径克制（8px），卡片 12px，面板 16px；阴影只用于浮层和可交互卡片。
5. 动效只帮助判断状态，默认 120–280ms，并尊重 `prefers-reduced-motion`。

## 保留的品牌决策

- 冷蓝主色 `#3f6f9f`，浅色优先。
- 五套主题：深海波纹、樱庭、极光机甲、星夜紫、墨白，以及自定义强调色。
- 深色模式跟随系统或用户选择，不是机械反相。
- 铭牌、头像框、身份称号等会员视觉资产保留；它们属于产品辨识度，不强行统一成普通徽章。
- 知识库、社区、导师、积分商城、后台的现有信息架构不变。

## 颜色

采用语义角色，不直接在组件里写随机 HEX：

| 角色 | Light | Dark |
|---|---|---|
| 页面背景 | `#f7f8fa` | `#111923` 混入主题色 |
| 面板 | `#ffffff` | `#19232f` |
| 次级面板 | `#f2f4f7` | `#151f2a` |
| 主文本 | `#18212c` | `#f0f4f8` |
| 次文本 | `#596574` | `#aeb9c7` |
| 边框 | `#d8dee7` | `#354354` |
| 主操作 | 主题强调色 | 主题强调色的深色可读变体 |
| 成功 | `#1d6e4e` | `#6dd3a8` |
| 警告 | `#7f5610` | `#f0c36a` |
| 信息 | `#2563a8` | `#8bbcf5` |
| 危险 | `#b4232e` | `#ff7b85` |

规则：

- 主操作色只用于主要动作、当前导航和关键数字；不要用于所有标题和说明。
- 状态色必须配套文字或图标，不能只靠颜色表达。
- 自定义强调色继续通过现有 `appearance.ts` 的可读性算法派生前景色；不要绕过对比度计算。
- 装饰性铭牌渐变属于品牌例外，已隔离在 `.identity-*` 规则内。

## 排版

| 角色 | 规格 | 用途 |
|---|---|---|
| display | `clamp(2.5rem, 6vw, 4.5rem)` / 1.04 | 首页主标题 |
| title | `clamp(1.75rem, 3vw, 2.5rem)` / 1.2 | 页面标题 |
| heading | 1.5rem / 1.35 | 区块标题 |
| body | 1rem / 1.6 | 正文与表单 |
| body-sm | .875rem / 1.6 | 辅助信息、列表 |
| caption | .75rem / 1.5 | 标签、时间、单位 |

- 字体栈：`PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC`、`Helvetica Neue`、`Arial`。
- 中文标题使用 `text-wrap: balance`；正文不强制均衡换行。
- 数值、金额、统计使用 `font-variant-numeric: tabular-nums`。
- 不通过任意缩小字号解决移动端布局；改为换行、重排或折叠。

## 空间与形状

- 基础节奏 4px；常用 4/8/12/16/24/32/48/64。
- 控件高度 44px；移动端主要操作至少 44px。
- 容器：常规页面 `max-w-7xl`，知识库 `max-w-6xl`，后台 `max-w-[100rem]`。
- 控件 8px、卡片 12px、面板 16px、药丸 9999px。
- 1px 边框；不用 0.5px 替代视觉层级。

## 层级与动效

- `--shadow-xs`：静态卡片和控件。
- `--shadow-card` / `--shadow-card-hover`：可交互卡片。
- `--shadow-floating`：弹层、浮窗。
- 动效：fast 120ms、normal 200ms、slow 280ms；只对颜色、边框、阴影和必要的进入/退出做过渡。
- 全局和组件均尊重 `prefers-reduced-motion` 与用户的“减少动态效果”设置。

## 响应式

至少检查 320、390、768、1024、1280、1440px。窄屏优先重排而不是隐藏关键功能；正文保持可读行宽，表格和长链接允许横向滚动但有明确边界。
