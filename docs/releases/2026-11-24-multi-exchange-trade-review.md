# WaveKB 多平台自动交易复盘发布说明

发布日期：2026-11-24
数据库标记：`202611240002`
发布方式：数据库与 Gateway 先行，交易同步验证后再启用网站总开关。

## 用户可见更新

- 交易工作台改为自动复盘首页，支持合并查看多个平台、多个账户的权益、累计净盈利、交易日历和归因分析。
- 首批只读平台：Binance USD-M、OKX、Bybit、Bitget、Exness。
- 每个账户单独管理，可验证、连接、立即同步、更新只读凭证、断开连接和申请删除数据。
- 自动还原完整交易周期；每笔交易可写复盘，也可调用站内知识库 AI 生成带引用的复盘建议。
- 保留旧版私人记录、研究草稿、历史分析工具和 AI 模型设置入口。
- 收益榜继续使用实时口径，并显示收益率、账户权益和累计盈利；金额公开仍需用户单独同意。

## 安全与隐私

- 所有交易所适配器只读取账户、成交、费用、资金费/隔夜费和出入金历史，不提供下单、撤单、转账或提现接口。
- 凭证仅在服务端加密保存；日志、网页、发布预检和收益榜不输出 API Key、Secret 或私钥。
- 用户可以隐藏并申请删除交易数据；后台定时任务执行到期硬删除和审计记录保留期清理。
- 五个平台和新版工作台均有独立严格布尔开关，默认关闭；旧工作台可作为即时回退界面。

## 发布顺序

1. 记录当前生产代码 SHA、数据库标记和 Gateway 环境文件备份。
2. 依次应用 `202611240001_multi_exchange_trade_review.sql` 和 `202611240002_trade_review_ai.sql`。
3. 发布 Gateway 与交易同步 systemd 单元，保持所有交易开关关闭。
4. 逐个平台打开只读适配器并运行一次同步，确认失败数为 0、数据覆盖时间和保留期清理正常。
5. 打开 `TRADING_WORKBENCH_V2_ENABLED`，运行桌面、移动端、旧入口、收益榜和禁止下单接口验收。
6. 验收通过后保留不可变发布目录和前一版本 SHA 作为回滚目标。

## 回滚

- UI 异常：将 `TRADING_WORKBENCH_V2_ENABLED=false`，立即回到旧工作台。
- 单个平台异常：只关闭对应的 `TRADING_PROVIDER_*_ENABLED`，其他平台继续同步。
- Gateway 异常：恢复上一不可变 Gateway 目录、systemd 单元和环境文件备份。
- Next.js 异常：执行现有精确回滚流程恢复上一发布 SHA。
- 数据库迁移为向前兼容的加法迁移，代码回滚不删除新表；禁止为回滚直接丢表或删除用户数据。

## 发布验收证据

发布流水线应保存以下非敏感证据：发布 SHA、回滚 SHA、数据库标记、已启用平台列表、最近同步时间、checked/failed 计数、生产健康检查、Playwright 报告和构建日志。任何证据不得包含交易所凭证或原始交易请求体。
